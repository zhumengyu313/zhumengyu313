## 🦁 代表项目 · 小狮子文件转换

**用浏览器操作，由本机完成转换。** 支持常见图片、音频、视频和部分文档格式，文件无需上传到第三方云服务。

- **本地优先**：浏览器负责选文件和查看进度，本机 Node.js 服务执行转换。
- **按格式调用引擎**：图片走 Sharp，音视频走 FFmpeg，文档按需使用 pdf2docx 或 LibreOffice。
